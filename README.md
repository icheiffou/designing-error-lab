 ## Designing Error — Research Lab

This repository documents an ongoing research inquiry into
productive failure across digital-to-physical design systems.

The work treats error, approximation, and constraint not as defects,
but as generative forces that emerge through translation between
simulation, representation, machine execution, and material behavior.

## Research Questions
- Where does error emerge across digital-to-physical pipelines?
- How do small parameter changes propagate across interconnected systems?
- What forms of structure appear when intention is translated through tools?

## Method
Each experiment follows a consistent structure:
1. System mapping
2. Parameter definition
3. Controlled variation
4. Physical execution
5. Failure documentation
6. Analytical reflection

## What This Repository Is
- A research lab notebook
- A reproducible process archive
- A documentation-first system

## What This Repository Is Not
- A software product
- An optimization exercise
- A portfolio of finished artifacts
